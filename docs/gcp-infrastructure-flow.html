1. Infrastructure Overview

APIX uses Google Cloud Platform for backend infrastructure. Cloud Run hosts the main API servers, Cloud Functions execute on-chain graduation transactions, Cloud Tasks provides job queuing with deduplication, and Firestore stores all application data.

2. Complete Graduation Flow

When a user makes an API call, the backend processes payment, tracks earnings, and checks if the graduation threshold is crossed. If crossed, a Cloud Task is dispatched which triggers the internal graduation handler. The handler builds a Merkle tree and calls the appropriate Cloud Function to execute the on-chain transaction.

4. Cloud Tasks Deduplication

Multiple concurrent requests may cross the graduation threshold simultaneously. Cloud Tasks uses named tasks to ensure graduation is only processed once. Duplicate task creation returns ALREADY_EXISTS which is silently ignored.

6. Solana Graduation Sequence

For Solana, the graduation-solana Cloud Function first fetches all earnings from the backend, then calls batch_mint in chunks of 50 users to mint tokens, and finally calls deploy_liquidity.

9. Deployment Commands

Quick reference for deploying all services. 
# Deploy Cloud Run backends
gcloud run deploy apix-backend --source . --region us-central1 --allow-unauthenticated
gcloud run deploy apix-backend-v2 --source . --region us-central1 --allow-unauthenticated --min-instances=1

# Deploy Cloud Functions
cd cloud-functions/graduation-evm
gcloud functions deploy graduation-evm --gen2 --runtime=nodejs20 --region=us-central1 \
  --source=. --entry-point=graduateEvm --trigger-http --allow-unauthenticated --timeout=540s

cd ../graduation-solana
gcloud functions deploy graduation-solana --gen2 --runtime=nodejs20 --region=us-central1 \
  --source=. --entry-point=graduateSolana --trigger-http --allow-unauthenticated --timeout=540s

# Set test graduation threshold
gcloud run services update apix-backend-v2 --region us-central1 \
  --set-env-vars "TEST_GRADUATION_THRESHOLD=1250000000000000000000"

# Remove test threshold
gcloud run services update apix-backend-v2 --region us-central1 \
  --remove-env-vars "TEST_GRADUATION_THRESHOLD"
