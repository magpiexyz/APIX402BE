2. Full Graduation Sequence

Step-by-step flow from a user's API call through to on-chain graduation. The user gets their response at step 5 — everything after is async.

sequenceDiagram
    autonumber
    participant U as API Consumer
    participant CR as Cloud Run Backend
    participant B as Builder API
    participant FS as Firestore
    participant CT as Cloud Tasks
    participant L as AWS Lambda
    participant BC as Blockchain

    U->>CR: POST /api/server/api + PAYMENT-SIGNATURE header

    CR->>CR: verifyPaymentAuthorization() — check signature without settling

    CR->>B: Forward request with X-IAO-Auth JWT
    B-->>CR: 2xx response with data

    CR->>CR: executePaymentTransfer() — settle payment on-chain

    CR->>U: Return builder response + payment confirmation header

    Note over CR,FS: Post-payment async block (fire-and-forget, non-blocking)

    CR->>FS: earningsService.incrementEarnings(token, user, tokensEarned, fee)
    CR->>FS: dynamoDBService.incrementVirtualDistributed(token, tokensEarned)
Uses Firestore runTransaction() for atomicity

    FS-->>CR: { newTotal, chainId, graduated, totalFeesCollected }

    Note over CR: Layer 1: Firestore Transaction
Atomic read+increment guarantees
accurate threshold comparison

    alt newTotal >= graduationThreshold AND NOT graduated
        CR->>CT: dispatchGraduationTask({ tokenAddress, chainId, ... })
Named task: graduate-{tokenAddress}

        Note over CT: Layer 2: Cloud Tasks Named Task
ALREADY_EXISTS (gRPC 6) silently ignored
10 concurrent API calls = 1 task

        CT->>CR: POST /internal/graduate/:tokenAddress
X-Graduation-Secret header
Retries: 5 attempts, 60s-600s backoff

        CR->>FS: Check token.graduated flag
        FS-->>CR: graduated = false (proceed)

        CR->>FS: acquireGraduationLock(tokenAddress)
Firestore transaction, 5-min TTL

        Note over CR,FS: Layer 3: Graduation Lock
Prevents duplicate execution
Auto-expires after 5 minutes

        FS-->>CR: Lock acquired = true

        CR->>FS: earningsService.getEarningsByToken(tokenAddress)
        FS-->>CR: [{userAddress, totalTokensEarned}, ...]

        CR->>CR: StandardMerkleTree.of(leaves, ['address', 'uint256'])
Build tree from earnings, extract root

        CR->>FS: merkleTreeService.storeMerkleTree(tokenAddress, {
  merkleRoot, leaves, treeDump, totalTokens, ... })

        CR->>FS: Update iao-tokens/{addr}.merkleRoot = root

        CR->>L: lambda.invoke({ action: 'graduate',
  tokenAddress, chainId, merkleRoot,
  virtualDistributed, totalFeesCollected })
InvocationType: Event (async, 202 accepted)

        CR->>FS: releaseGraduationLock(tokenAddress)

        Note over L,BC: Lambda executes asynchronously

        alt EVM Chain (numeric chainId)
            L->>BC: TokenDistributor.graduateTokenWithMerkle(
  token, merkleRoot, virtualDistributed, feesCollected)
Sets merkle root on-chain + deploys Uniswap V4 liquidity
        else Solana Chain (devnet/mainnet-beta)
            L->>CR: GET /internal/graduation-earnings/:token
Fetch per-user earnings breakdown
            CR-->>L: { earnings: [{userAddress, totalTokensEarned}, ...] }
            L->>BC: batch_mint(recipients, amounts, fees)
Chunks of 50 recipients per TX
            L->>BC: deploy_liquidity()
Marks token as graduated on-chain
        end

        BC-->>L: TX confirmed, txHash

        L->>CR: POST /internal/graduation-confirm/:tokenAddress
{ txHash: "0x..." }

        CR->>FS: Update iao-tokens/{addr}.graduated = true
        CR->>FS: Update merkle-trees/{addr}.setOnChainTxHash = txHash
    end

4. Internal API Endpoints

Three internal endpoints coordinate graduation. All require X-Graduation-Secret header when GRADUATION_INTERNAL_SECRET is set.

Endpoint Called By Purpose Key Behavior
POST /internal/graduate/:tokenAddress Cloud Tasks Build Merkle tree and invoke Lambda Returns 200 already_graduated if token graduated.
Returns 409 if lock held.
Returns 500 on failure (Cloud Tasks retries).
Acquires + releases graduation lock.
POST /internal/graduation-confirm/:tokenAddress Lambda Set graduated=true after on-chain TX Receives { txHash } in body.
Updates iao-tokens/{addr}.graduated = true.
Stores txHash on merkle-trees doc (non-fatal if missing).
GET /internal/graduation-earnings/:tokenAddress Solana Lambda Fetch per-user earnings for batch_mint Returns { earnings: [{userAddress, totalTokensEarned}] }.
Only needed for Solana (EVM uses merkleRoot directly).

6. EVM vs Solana Graduation Path

The backend builds the Merkle tree identically for both chains. The Lambda execution differs.

EVM (Base Sepolia) — chainId: "84532"

  • Lambda: graduation-evm
  • Single TX: TokenDistributor.graduateTokenWithMerkle(token, merkleRoot, virtualDistributed, feesCollected)
  • Contract internally calls IAOTokenV2.graduateWithMerkle() which:
    • Stores merkleRoot on-chain
    • Sets totalTokensDistributed = virtualDistributed
    • Calls _deployLiquidity() → Uniswap V4 pool + LpGuardHook
  • Users claim tokens via Merkle proof: claim(amount, proof[])
  • Graduation threshold: 625,000,000 * 10^18

Solana (Devnet) — chainId: "devnet"

  • Lambda: graduation-solana
  • Multi-step:
    • Fetches earnings via GET /internal/graduation-earnings/:token
    • Calls batch_mint(recipients, amounts, fees) in chunks of 50
    • Creates ATAs for recipients who don't have them
    • Calls deploy_liquidity() after threshold crossed on-chain
  • Tokens minted directly to user wallets (no Merkle claim)
  • Program ID: FpCX6E1LxRph23NJgF9R8haRJscGPbbdhP2vd5Sn6jwA
  • Graduation threshold: 625,000,000 * 10^9

10. Infrastructure Setup Checklist

GCP — Cloud Tasks Queue

gcloud tasks queues create graduation-queue --location=us-central1 --max-dispatches-per-second=1 --max-concurrent-dispatches=1 --max-attempts=5 --min-backoff=60s --max-backoff=600s

AWS — IAM User

Create IAM user cloud-run-graduation with lambda:InvokeFunction permission scoped to the two Lambda ARNs. Generate access keys for Cloud Run env vars.

AWS — Deploy Lambdas

cd lambdas/graduation-evm && npm install && npm run build && npm run deploy
cd lambdas/graduation-solana && npm install && npm run build && npm run deploy

Local Testing

yarn dev in terminal 1
npx tsx scripts/test-graduation-local.ts in terminal 2
Tests all 10 stages without Cloud Tasks or Lambda.
