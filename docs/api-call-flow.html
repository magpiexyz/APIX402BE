EVM Flow (x402 / EIP-3009)

sequenceDiagram participant U as User Wallet participant F as Frontend participant P as IAO Proxy participant B as Builder API participant T as Thirdweb participant C as IAOToken U->>F: 1. Request API call F->>U: 2. Request EIP-3009 signature U->>F: 3. Sign transferWithAuthorization
(to facilitator address) F->>P: 4. POST /api/:slug/:api
+ PAYMENT-SIGNATURE header
(base64 JSON) P->>P: 5. verifyPaymentAuthorization()
(don't settle yet) P->>B: 6. Forward request
+ X-IAO-Auth JWT B->>P: 7. Response (2xx/4xx/5xx) alt Success (2xx) P->>T: 8. executePaymentTransfer()
calls settlePayment() T->>C: 9. Transfer USDC to IAOToken P->>P: 10. Queue in request-queue
+ update api-metrics P->>F: 11. Return data + receipt else Failure (4xx/5xx) P->>F: 11. Return error
(no charge) end Note over P: Automation polls queue
and calls batchMint F->>U: 12. Display result

Solana Flow (SPL Token Transfer)

sequenceDiagram participant U as User Wallet
(Phantom/Solflare) participant F as Frontend participant P as IAO Proxy participant B as Builder API participant SOL as Solana RPC U->>F: 1. Request API call F->>U: 2. Request SPL transfer signature U->>F: 3. Sign USDC transfer tx
(to program vault PDA) F->>P: 4. POST /api/:slug/:api
+ PAYMENT-SIGNATURE header
(network: "solana:devnet",
signedTransaction + authorization) P->>P: 5. Verify authorization:
to === tokenAddress (case-sensitive)
amount >= api.fee P->>B: 6. Forward request
+ X-IAO-Auth JWT B->>P: 7. Response (2xx/4xx/5xx) alt Success (2xx) P->>SOL: 8. sendRawTransaction
(submit signed tx) SOL->>SOL: 9. confirmTransaction
(USDC to vault PDA) P->>P: 10. Async: track earnings
incrementVirtualDistributed
+ increment pendingFees P->>P: 11. Check graduation threshold P->>F: 12. Return data + receipt else Failure (4xx/5xx) P->>F: 12. Return error
(tx not submitted) end Note over P: At graduation: Merkle tree built,
users claim tokens via proofs F->>U: 13. Display result
